## 👋 About Me

I'm a **Full Stack Developer** focused on turning real needs into maintainable, efficient, and scalable software—from backend services and APIs to frontend applications.

Good software is not about adopting the most technologies or building the most complex system. It is about making the right technical decisions to balance **cost, efficiency, maintainability, and scalability**.

- 🔭 Building full-stack applications and backend services.
- 🌱 Deepening my skills in **Angular, Java/Spring Boot, software architecture, and cloud technologies**.
- 🧩 Exploring **Go and .NET** while strengthening my core stack.
- 💬 Open to conversations about APIs, architecture, automation, and pragmatic engineering.
